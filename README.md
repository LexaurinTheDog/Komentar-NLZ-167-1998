# Komentář k zákonu č. 167/1998 Sb., o návykových látkách a o změně některých dalších zákonů

Otevřený komentář k zákonu o návykových látkách — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; povolení k zacházení s návykovými látkami, způsobilost, vývoz a dovoz, konopí pro léčebné použití a technické konopí, mák a makovina, evidence, psychomodulační látky, léčebný psilocybin, kontrola a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-1998-00167_2026-01-01`.
